# Saba Fiorentini — sito web (statico)

Sito one-page (solo **HTML/CSS**) per **Saba Fiorentini, Psicologa**.

## Contenuti
- `index.html`: pagina principale con sezioni e menu ad ancore
- `styles.css`: stile del sito
- `assets/`: immagini e risorse
- `robots.txt` / `sitemap.xml`: indicizzazione Google
- `CNAME`: dominio custom per GitHub Pages (`www.sabafiorentinipsicologa.it`)

## Form contatti
La form invia email a `sabafiorentini.psi@gmail.com` tramite **FormSubmit** (`formsubmit.co`), quindi non serve PHP o backend.

## Pubblicazione (GitHub Pages)
1. Push su GitHub
2. GitHub → **Settings → Pages** → deploy da branch `main` (root)
3. Imposta **Custom domain**: `www.sabafiorentinipsicologa.it`
